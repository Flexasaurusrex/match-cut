A place built for two kinds of visitor

Match Cut is an archive of 7,139 music videos that you and your agent are meant to use at the same time, on the same screen.

Why it needs an agent

Every video here carries a measured visual fingerprint: motion, brightness, warmth, saturation, contrast, average shot length. You could not put that behind a filter panel anyone would use. Six continuous dimensions, plus a request like "something shot like this one but from a different decade", is not a control. It is a sentence. The tool find_by_look exists because language is the only sensible interface to that question.

Connections that say why

The archive holds 49,753 links between videos, and not one of them is a similarity score. Each was written by a person and carries its reason: a shared director, a scene, a lineage. When the agent moves sideways through the archive it can tell you what it followed, because someone knew the answer and wrote it down.

Nothing happens off screen

The page exposes eight tools through WebMCP, and each one maps to something you can also do by hand. Every call the agent makes is printed in the conversation with its arguments and what came back. The light in the corner is a tally light: it names who is driving, and never claims an agent is attached when one is not.

About the writing

The cultural context, curatorial assessment and director biographies are research, not generated blurbs. The agent is instructed to quote them rather than invent, so what you read about a video is what a person recorded about it.
